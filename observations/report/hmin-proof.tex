At the lowest point of its path, the star is on the opposite side of the celestial pole.

Using the same idea as before, the angular distance from the zenith is now

\[
z = \mathrm{lat} + \delta_*
\]

Since altitude and zenith distance satisfy

\[
h_{\min} + z = 90^\circ
\]

we get

\[
h_{\min} + (\mathrm{lat} + \delta_*) = 90^\circ
\]

and therefore

\[
h_{\min} = 90^\circ - \mathrm{lat} - \delta_*
\]

If this value is negative, the star is below the horizon at its lowest point.
